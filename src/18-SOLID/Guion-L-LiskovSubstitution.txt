Este metodo parece inofensivo, pero esconde una trampa.

CuentaAhorro hereda de Cuenta, pero mira lo que hace: retirar() en Cuenta nunca falla, resta cualquier monto sin preguntar. CuentaAhorro lo sobreescribe y ahora lanza una excepcion si no hay fondos.

¿Y por que es un problema? Porque si un proceso recorre una lista de cuentas dando por hecho que retirar() siempre funciona, como prometia Cuenta, el dia que llega una CuentaAhorro sin saldo, todo explota con una excepcion que nadie esperaba.

Eso es justo lo que dice Liskov: tienes que poder sustituir la clase padre por la hija sin que el comportamiento cambie de forma inesperada. Aqui CuentaAhorro aprieta un contrato que Cuenta prometia mas permisivo.

Asi que la solucion es hacer el contrato honesto desde el principio: Cuenta pasa a ser una interfaz que ya deja claro que retirar() puede rechazar la operacion.

Ahora, CuentaAhorro implementa esa interfaz con el contrato explicito. Nadie se lleva sorpresas.

---

CODIGO:

// MAL - Cuenta promete que retirar() nunca falla.
class Cuenta {
    protected double saldo;
    Cuenta(double saldoInicial) { this.saldo = saldoInicial; }
    void retirar(double monto) { saldo -= monto; }
    double getSaldo() { return saldo; }
}

// Viola LSP: aprieta el contrato lanzando una excepcion que Cuenta nunca prometio
class CuentaAhorro extends Cuenta {
    CuentaAhorro(double saldoInicial) { super(saldoInicial); }
    @Override
    void retirar(double monto) {
        if (saldo - monto < 0) throw new IllegalStateException("Saldo insuficiente");
        saldo -= monto;
    }
}

// BIEN - El contrato se declara honesto desde el principio
interface CuentaBancaria {
    double getSaldo();
    void retirar(double monto); // puede lanzar IllegalStateException si no hay fondos
}

class CuentaAhorroOk implements CuentaBancaria {
    private double saldo;
    CuentaAhorroOk(double saldoInicial) { this.saldo = saldoInicial; }
    public double getSaldo() { return saldo; }
    public void retirar(double monto) {
        if (saldo - monto < 0) throw new IllegalStateException("Saldo insuficiente");
        saldo -= monto;
    }
}

public class ExpLiskovSubstitution {
    public static void main(String[] args) {
        // Violacion: el proceso da por hecho que retirar() nunca falla
        Cuenta cuenta = new CuentaAhorro(100);
        try {
            cuenta.retirar(150); // el proceso no esperaba esta excepcion
        } catch (IllegalStateException e) {
            System.out.println("Fallo inesperado: " + e.getMessage());
        }

        // Correcto: el contrato ya avisa que puede fallar
        CuentaBancaria cuentaOk = new CuentaAhorroOk(100);
        try {
            cuentaOk.retirar(150);
        } catch (IllegalStateException e) {
            System.out.println("Retiro rechazado: " + e.getMessage());
        }
    }
}
