# Colecciones Deque — Ejercicios Fácil

Operaciones básicas con ArrayDeque como Stack y Queue, peekFirst/peekLast, palíndromo, undo.

Las soluciones están en [soluciones/](soluciones/).

---

## Ejercicio 1 — ArrayDeque como Stack LIFO

Usa push/pop/peek de ArrayDeque como stack. Apila 5 strings y desapílalos mostrando el orden LIFO.

## Ejercicio 2 — ArrayDeque como Queue FIFO

Usa offerLast/pollFirst para comportamiento FIFO. Añade 5 elementos y extráelos mostrando el orden FIFO.

## Ejercicio 3 — Invertir lista con Deque

Usa un Deque como stack auxiliar para invertir el contenido de una lista. Sin usar Collections.reverse().

## Ejercicio 4 — Historial de acciones (undo)

Simula acciones de un editor: cada acción se apila. Undo desapila la última. Muestra el historial después de varias acciones y un undo.

## Ejercicio 5 — Palíndromo con Deque

Verifica si una cadena es palíndromo usando Deque: añade cada carácter, luego compara extremos con pollFirst/pollLast.

## Ejercicio 6 — peekFirst y peekLast

Crea un Deque con 5 elementos. Muestra cómo peekFirst y peekLast ven ambos extremos sin modificar el Deque. Verifica que el tamaño no cambia.
