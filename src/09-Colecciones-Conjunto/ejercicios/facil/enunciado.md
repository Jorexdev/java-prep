# Colecciones Conjunto — Ejercicios Fácil

Operaciones básicas con HashSet, LinkedHashSet, TreeSet, EnumSet. Eliminar duplicados, operaciones de conjuntos.

Las soluciones están en [soluciones/](soluciones/).

---

## Ejercicio 1 — Eliminar duplicados con HashSet

Dada una lista con elementos repetidos, usa HashSet para eliminar los duplicados. Muestra la lista original y el conjunto resultante.

## Ejercicio 2 — Intersección de conjuntos

Dadas dos listas de strings, encuentra los elementos comunes usando HashSet y retainAll.

## Ejercicio 3 — LinkedHashSet preserva orden

Inserta los mismos elementos primero en HashSet y luego en LinkedHashSet. Muestra que LinkedHashSet conserva el orden de inserción.

## Ejercicio 4 — TreeSet en orden natural

Crea un TreeSet de strings. Demuestra que los elementos están siempre ordenados alfabéticamente al añadir o iterar.

## Ejercicio 5 — Diferencia entre conjuntos

Dado conjunto A y conjunto B, calcula A - B (elementos en A que no están en B) usando removeAll.

## Ejercicio 6 — EnumSet con días laborables

Define enum Dia{LUNES,MARTES,MIERCOLES,JUEVES,VIERNES,SABADO,DOMINGO}. Crea EnumSet.of para días laborables y usa complementOf para obtener el fin de semana.
